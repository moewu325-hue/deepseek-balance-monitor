# 本地余额界面一致性设计

日期：2026-08-05  
状态：已获用户逐段确认

## 目标

把旧版本地余额监控的悬浮面板、鲸鱼气泡、点击反馈、峰谷提示和游动动画移植到新版安全架构中。界面观感与主要交互保持一致，同时继续使用新版的凭据隔离、严格余额解析、单币种显示、原子存储和安全退出逻辑。

## 非目标

- 不恢复配置文件中的明文 API Key。
- 不执行 Claude `apiKeyHelper`，不扩大自动凭据发现范围。
- 不跨币种求和；面板只显示首选币种或唯一可用币种。
- 不根据“高峰 ×2”再次加工余额或今日减少值。余额服务返回的扣费结果已经反映实际计费，高峰状态只作费率提醒。
- 不把网络、凭据写入、配置写入或历史写入移回 Tk 主线程。

## 依据与约束

- 旧版界面是视觉和交互基准。
- 用户提供的 DeepSeek 开放平台通知规定：峰谷定价统一按北京时间计算，每日 09:00–12:00 和 14:00–18:00 为高峰，高峰适用于所有计费项且价格为平时两倍；实际生效时间以正式通知为准。
- [第一财经报道](https://finance.sina.com.cn/stock/roll/2026-06-30/doc-inifczzw4923841.shtml)和[腾讯云同步调价公告](https://docs.cloudbase.net/ai/announcement/deepseek-v4-price-update)可交叉印证时段与价格倍数。
- 用户明确选择把旧鲸鱼图标纳入仓库，并接受其来源和再发布授权未核实的风险。仓库必须如实记录该状态，不得虚构授权。

## 架构

### 组件边界

1. `CanvasMonitorView`
   - 只负责 Tk/Canvas 绘制、动画、鼠标事件、菜单和确认弹窗。
   - 只接收不含凭据的显示模型和状态事件。
   - 所有 Tk 调用只在主线程执行。

2. `BalanceController`
   - 保留现有后台发现、余额刷新、401 恢复和刷新合并逻辑。
   - 不向界面暴露 API Key。

3. `UsageRecorder`
   - 保留现有按币种记录、相邻去重、10,000 条上限及原子写入逻辑。
   - 向界面发布“今日余额减少（估算）”。

4. `PeakSchedule`
   - 纯逻辑组件，使用 `zoneinfo.ZoneInfo("Asia/Shanghai")`。
   - 高峰区间为 `[09:00, 12:00)` 和 `[14:00, 18:00)`，每日生效。
   - 不读取电脑本地时区，不受外国地区夏令时影响。

5. `StartupManager`
   - 只管理本应用在 Windows Startup 目录中的专属启动入口。
   - 开启、关闭均幂等；删除时不得影响其他启动项。
   - 启动入口只包含应用启动命令，不包含 API Key 或其他凭据。

6. `SettingsWriter`
   - 合并并后台保存窗口位置、面板/气泡状态、透明度和自启动状态。
   - 使用现有严格九字段配置和原子替换流程。

7. `app.py`
   - 负责引导、人工凭据恢复和组件组装。
   - 不继续承载大段 Canvas 绘制与动画实现。

### 数据流

```text
CredentialResolver -> BalanceController -> sanitized display event
                                            |
                                            v
                                      CanvasMonitorView
                                            |
                         selected currency + total balance
                                            v
                                       UsageRecorder
                                            |
                               estimated daily decrease event
                                            v
                                      CanvasMonitorView
```

“立即刷新”只向控制器提交一次可合并命令。Canvas 每秒自行更新“距上次刷新时间”和峰谷状态；跨越峰谷边界无需再次请求余额。

## 视觉规格

### 完整面板

- 窗口尺寸：255×215。
- 无系统边框、置顶显示，透明度使用配置值。
- 基础颜色：
  - 背景 `#060b18`
  - 面板 `#0c1430`
  - 主青色 `#00e5ff`
  - 辅助蓝 `#2979ff`
  - 辅助紫 `#7c4dff`
  - 主文字 `#e0f7ff`
  - 弱文字 `#4a6d8c`
  - 正常 `#00e676`
  - 警告 `#ffab00`
  - 错误 `#ff1744`
  - 高峰 `#ff5252`
- 数据字体优先使用 Consolas。
- 从上到下显示：
  1. `DEEPSEEK ONLINE` 或错误/低余额状态
  2. 首选币种总余额
  3. 同币种充值余额
  4. 今日余额减少（估算）
  5. 峰谷状态
  6. 距上次刷新秒数
- 高峰文案：`▲ 高峰期 · 双倍消耗`。
- 非高峰文案：`● 非高峰 · 正常计费`。
- 右上角并排放置：
  - `◉`：缩小为鲸鱼气泡
  - `✕`：退出
- 不再在右下角显示退出按钮。

### 鲸鱼气泡

- 透明窗口尺寸：100×100。
- 气泡主体直径：80px。
- 鲸鱼图标：44px。
- 保留外圈光晕、三层涟漪、五个上浮粒子和状态光环。
- 高峰时主体使用偏红底色 `#241014`，状态光环使用 `#ff5252`。
- 图标加载失败时使用 `DS` 文字占位，不影响余额功能。

## 动画

- 整个气泡围绕用户停靠锚点水平往返约 50px，并上下浮动约 8px。
- 每 50ms 更新一帧，并限制在屏幕安全边界内。
- 鲸鱼同步进行小角度摆动。
- 进入气泡模式时执行短暂淡入。
- 鼠标按下时暂停游动，鲸鱼轻微缩放并产生一圈点击水波。
- 未发生拖拽时，松开鼠标后展开完整面板。
- 拖拽时更新锚点，松开后恢复游动并后台保存位置。
- 若鼠标释放事件丢失，3 秒后取消拖拽状态并恢复游动。
- 退出或切换为完整面板时必须取消所有动画计时器。

## 交互

### 完整面板

- 左键拖拽移动窗口。
- 双击非按钮区域打开 DeepSeek 用量控制台。
- `◉` 缩小为气泡。
- `✕` 发起退出确认。
- 右键菜单包含：缩小为气泡、立即刷新、DeepSeek 控制台、开机自启动、退出。

### 鲸鱼气泡

- 单击播放反馈并展开完整面板。
- 拖拽移动锚点。
- 右键菜单包含：展开、立即刷新、开机自启动、退出。

### 状态记忆

- 启动时恢复上次的面板或气泡状态。
- 恢复上次窗口位置；超出当前屏幕范围时回退到安全位置。

### 退出确认

所有退出入口，包括右上角 `✕`、两个右键菜单的“退出”和系统关闭事件，统一显示：

`确定要退出 DeepSeek 余额监控吗？`

- 选择“否”：关闭弹窗并继续运行，不停止刷新或动画。
- 选择“是”：拒绝新任务、停止动画、保存最终状态、等待所有后台任务完全结束，然后释放单实例互斥锁并退出。
- 重复触发确认或退出只能执行一次关闭流程。

## 开机自启动

- 默认关闭，由用户通过右键菜单复选项主动选择。
- 开启操作在后台创建本应用专属启动入口；创建成功后才保存 `auto_start=true`。
- 关闭操作在后台删除本应用专属入口；删除成功后才保存 `auto_start=false`。
- 操作期间菜单项不可重复触发。
- 失败时恢复原复选状态，并显示通用错误提示，不展示本机路径或系统内部错误。
- 应用启动时校验配置与实际启动入口是否一致，以实际入口为准修正界面状态。

## 错误处理

- API 错误保留上次成功余额，显示通用同步失败状态。
- 401 继续走现有凭据重新发现和人工恢复流程。
- 多币种且首选币种不存在时，不回退求和，显示“首选币种不可用”。
- 配置、历史、自启动或图标异常不得阻止安全退出。
- UI、弹窗、日志和异常文本不得包含 API Key、认证头或原始凭据读取结果。

## 测试与验收

### 峰谷边界

- 08:59:59 非高峰，09:00:00 高峰。
- 11:59:59 高峰，12:00:00 非高峰。
- 13:59:59 非高峰，14:00:00 高峰。
- 17:59:59 高峰，18:00:00 非高峰。
- 输入时刻来自外国时区时，仍转换为北京时间得到相同结论。

### Canvas 与币种

- 以记录型 Canvas 验证窗口尺寸、绘制坐标、颜色、文字和按钮点击区域。
- 验证高峰红色样式与非高峰绿色样式。
- 验证只显示首选/唯一币种，不跨币种相加。
- 验证鲸鱼资源失败时使用文字占位。

### 动画与交互

- 验证按下缩放、水波反馈、单击展开、拖拽暂停/恢复和 3 秒安全恢复。
- 验证完整面板拖拽、双击控制台、右上角两个按钮和两个右键菜单。
- 验证面板/气泡状态与位置的后台保存和下次恢复。

### 退出

- 选择“否”后应用状态不变。
- 选择“是”只执行一次关闭。
- 所有已接受后台任务结束后才释放互斥锁。
- 已退役控制器和恢复任务也必须完成回收。

### 自启动

- 默认关闭。
- 重复开启和关闭均幂等。
- 取消只删除本应用入口。
- 启动入口不含任何凭据。
- 写入失败时配置和菜单复选状态回滚。

### 完整验证

- 运行所有现有测试与新增测试。
- 运行 `compileall`、离线 wheel/资源检查、依赖检查和仓库隐私扫描。
- 在 Windows 实机分别启动完整面板和鲸鱼气泡，与旧版截图对照。

## 风险与回滚

- 旧鲸鱼图标来源和再发布授权未核实。仓库 NOTICE 必须如实声明；若后续需要降低风险，可替换为原创图标而不改变 Canvas 接口。
- 高频 Canvas 重绘可能增加 CPU 使用。验收时记录静置 CPU；若明显高于旧版，优先缓存旋转帧和减少无变化重绘，不改变 50ms 运动节奏。
- 自启动入口依赖项目路径。项目移动后，启动校验会把失效状态显示为关闭，用户可在新位置重新开启。
- 回滚时删除新增 Canvas/峰谷/自启动模块并恢复当前 `BubbleApp` 组装；凭据、API、存储格式无需回滚。
