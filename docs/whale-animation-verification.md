# v2.1.0 鲸鱼动画与峰谷灯验证

日期：2026-10-22；Windows x64，本机125%缩放；沿用已核SHA256的Zig0.17.0，无新增运行依赖。

## 改动

- 72×72逻辑气泡内的鲸鱼左右往返、随方向翻转并摆尾；每16秒周期中，12.0–13.5秒跃起/落水，水花短暂显示。位移按单调时间计算，不按帧累计。
- 完整面板、气泡、任务栏条都有红色“高峰”/绿色“非高峰”标记。北京时间工作日09:00–12:00及14:00–18:00为高峰，终点不含；其余与周末非峰。提示沿用旧规则，不代表当前模型报价或倍率。
- 气泡约30FPS；静态模式不启用动画计时器。峰谷每秒及系统时间变化时独立检查，任务栏原有位置跟随保留。
- 数据目录、凭据来源、余额请求和自启动行为不变；不增加配置字段。

## 本机实际验证

命令：`native/build.ps1 -Zig <已核验Zig绝对路径> -Test -Live`，退出0。

- 核心69个断言，0失败；新增时间轨迹覆盖左右边界/转向、跳跃最高点/落水、负时间、最大整数和循环，峰谷灯映射两态均覆盖。
- Windows22个断言，0失败；实际无效凭据HTTP401及原子写入崩溃注入通过。
- 三模式真实窗口与PrintWindow通过：面板425×298、气泡90×90、任务栏230×58；保持TOOLWINDOW、非置顶、正常退出与原参数边界。
- 真实像素逐模式核对红/绿两态；冻结6个游动/跳跃时刻确认不同帧，16秒轨迹重复、金额像素区域不变、动画不移动窗口。
- 离线控制只在smoke实例接受；非法peak或elapsed输入拒绝且不改变灯色。正常实例不接受该消息。
- 离线smoke未修改真实config.json/usage_log.json，前后SHA256一致；没有读取真实凭据、发余额请求或改自启动。
- 另运行三模式各2秒GDI计数观察：气泡13→13，面板12→12，任务栏12→12；气泡双击展开面板通过。短观察用于发现明显泄漏，不是长期压力测试。
- README动画由原生离线窗口PrintWindow采集144帧，余额为合成数据；保留docs/whale-swim.gif作使用示例，其他核验帧清理。
- 独立只读审查未发现有证据的P1/P2，核对时间边界、GDI恢复释放、计时器模式切换和smoke输入隔离；编译器-Wall/-Wextra无告警。
