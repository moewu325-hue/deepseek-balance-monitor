# 鲸鱼动画与峰谷灯验证

## v2.2.0：可调大小的海景气泡

日期：2026-10-28；Windows x64，本机125%缩放，已核SHA256的Zig0.17.0。

- 默认圆形直径72→108逻辑像素，实际90×90→135×135，鲸鱼、金额与峰谷灯一同放大。右键「气泡大小」提供小/标准/大/超大/特大五档（72/90/108/132/160），即时生效并保存。
- 新增配置字段bubble_size：旧配置缺省108，仅接收72..160整数；布尔、浮点与越界值拒绝，沿用损坏配置保护。面板、任务栏和密钥对话框继续使用系统原比例。
- 新增独立ocean_scene.hpp，用现有GDI/Msimg32绘制月光、星点、薄云、远山、渐变海水、波纹和上升气泡，不加入位图或外部运行依赖。背景周期4秒，整除原鲸鱼16秒周期；动态区域不进入金额区。

## v2.1.1：DeepSeek 图标与抛物线跃出

日期：2026-10-22；Windows x64，本机125%缩放；使用已核SHA256的Zig0.17.0。

- 直接加载仓库现有的225×225 `assets/deepseek_icon.ico`，保留图案、颜色和透明边缘；原图头朝左，向右游动时镜像。使用预乘透明度采样和Windows内置Msimg32的AlphaBlend，旋转画布按缩放缓存，没有新增外部运行依赖。
- 16秒周期中，12.0–13.6秒为跃出段。以起跳为t=0，逻辑坐标为 `x=44-15t`、`y=34-35t+21.875t²`；水平速度恒定，屏幕向下为正的加速度为43.75逻辑像素/秒²。起跳(44,34)，0.8秒到最高点(32,20)，1.6秒落水(20,34)。
- 头部朝向跟随速度切线：起跳斜向上、最高点水平、下降斜向下；水下预备和落水恢复与飞行段的位置、速度和角度连续。水下速度接近零时收敛旋转角，避免停游交界处突然转头。
- 三模式红/绿峰谷灯、金额区域、用户窗口位置和既有配置保持原行为。
