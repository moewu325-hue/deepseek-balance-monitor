# 原生精简版实施与验证

用户于 2026-10-21 批准：现行项目根目录新增 C++/Win32 版，保留三种显示模式、旧配置与专用凭据兼容，单文件目标小于 1 MB，上传 moewu325-hue 私有仓库。

## 全局约束

Windows x64；C++17；Win32/GDI+ 绘制、WinHTTP HTTPS、Windows Credential Manager；不附带 Python、Tk、WebView 或第三方运行时。独立编写实现，只借鉴 CodexUsageBar 的系统 API 架构，不复制其源码。密钥只从 DEEPSEEK_API_KEY、DeepSeekBalanceMonitor.ApiKey 或明确输入读取，只向固定 api.deepseek.com/user/balance 发送，禁止重定向。金额按百万分之一单位精确计算，超过精度明确拒绝，绝不跨币种相加。UI 线程不发网络请求；单实例互斥名称与旧版一致。

## 范围与文件职责

- native/core.hpp、core.cpp：金额、响应与设置校验、按币种历史；负责人主代理。
- native/windows.hpp、windows.cpp：安全 HTTP、凭据、原子文件、自启动、定位；负责人主代理。
- native/app.cpp、main.cpp：三种视图、右键菜单、拖动、刷新、掩码密钥输入、命令行；独立实现任务，使用已冻结头文件接口。
- native/tests/core_tests.cpp、windows_tests.cpp 与 UI 冒烟：金额精度、多币种、畸形 JSON、旧配置及历史兼容、原子替换故障、单实例、三模式。
- native/build.ps1、CMakeLists.txt、README.md、CI：可复跑构建、版本及发布说明；负责人主代理。

## 证据与风险

旧版真实 --check 已于本日返回“凭据已验证”，接口测试 19/19 通过。完整 Python 基线 216 项存在 3 个断言失败、3 个 fake UI 错误，均在本轮实现前存在；另离线 wheel 失败源于系统 setuptools 版本不匹配。原有差异已在项目外临时保存，不覆盖、不丢弃。

外部接口文档：https://api-docs.deepseek.com/api/get-user-balance/ 。契约为 GET + Bearer，成功 application/json，is_available 和 balance_infos 中 currency、total_balance、granted_balance、topped_up_balance。发布前补原生真实成功/401、证书校验、响应大小上限及原子持久化故障证据；网络读取是只读，不存在远端写入幂等问题。配置与历史互斥由唯一进程+单工作线程保证，UI 通过消息接收完成结果。

失败模式：断网/凭据失效时清楚标记错误并保留旧余额；配置损坏时不自动覆盖原文件。边界：非 CNY/USD 币种、响应多币种、负余额、显示器变化、中文路径、旧自启动项。回滚：保留旧 Python 源码，验证新 EXE 后才替代桌面现行版本；Git 原生实现独立提交可回退。
