# 鲸鱼游动与峰谷灯实现计划

目标：用户2026-10-22要求气泡内鲸鱼左右游动、偶尔跃出水面，并在三种模式用红/绿灯区分高峰与非高峰；沿用现有原生小体积架构。

设计：72×72逻辑气泡内绘制水面与鲸鱼，左右往返并翻转方向，按单调时间计算游动与间歇跳跃；金额和峰谷短文字占独立区域。动画不移动用户窗口，不改变拖动、双击或右键交互。三模式复用峰谷灯，红为高峰、绿为非高峰，继续依据现有北京时间工作日时段规则，不代表实时定价。

文件职责：native/animation.hpp提供确定时间采样，app.cpp负责GDI绘制和计时器；core_tests及ui_smoke验证轨迹/像素/窗口/隔离；main.cpp与app.rc更新2.1.0。README中英文同步使用与构建说明，原验证记录保留历史并新增本次证据。

实施：

1. 先为左右边界、方向、跃起/落水、循环和异常时间写失败回归，再实现纯时间动画；保留原有业务测试。
2. 仅气泡启用约30FPS动画，静态视图低频检查峰谷切换；所有GDI对象在绘制内配对释放，金额区域不被鲸鱼遮挡。
3. 使用已锁定SHA256的Zig0.17.0构建，运行核心/Windows/UI自动检查；真实窗口分别核红绿两态与动画多个时间点，检查拖动/双击/右键回归及用户配置哈希不变。
4. 独立复核改动，发布v2.1.0并回下载核SHA256；新EXE验证后替换桌面入口，保留配置/凭据，清理本轮工具链、核验图与临时脚本。

失败模式：定时器累计帧数会在负载下减速，故改用实际单调时间；峰谷切换必须触发静态视图更新；GDI资源泄漏及文字碰撞需用真实多帧核验。

边界：窗口外框与数据格式不变，余额刷新仍按配置；日期/时段判断沿用原规则；离线smoke不得读凭据、发网络或改自启动。回滚可重新安装v2.0.0，配置与凭据无需迁移。
