# 放大海景气泡实施计划

目标：气泡默认直径由72增至108逻辑像素（增加50%，本机125%缩放为135×135），同步放大鲸鱼、金额和峰谷灯；背景增加月光、远山、层次海面、波纹与水下气泡。用户追加要求在设置中调节大小，右键菜单提供72/90/108/132/160五档并持久保存。

方案取舍：仅放大窗口会留下空白；放大现有画布并增加原生海景可保持交互和小体积，采用此方案。新场景不引入位图或运行时依赖。

结构：native/ocean_scene.hpp负责背景/前景绘制；app.cpp接入场景、气泡尺寸菜单与动态绘制比例。animation.hpp保留已有抛物线和朝向算法。不同模式的窗口布局、鼠标坐标和DPI仍使用实际系统比例，气泡绘图按bubble_size/72缩放，避免影响面板和密钥对话框。core.hpp/core.cpp新增bubble_size，旧配置缺省108，接收72..160整数，非法值沿用损坏配置保护，不覆盖原文件。
