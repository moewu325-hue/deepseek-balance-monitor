# DeepSeek图标与弧线跳跃

用户要求：气泡直接使用现有DeepSeek图标；跃出时头朝斜上，沿自然弧线落水。保留上一版三模式峰谷灯、拖动/双击、配置与凭据。

设计：复用assets/deepseek_icon.ico原始透明像素，缓存为位图后按方向镜像和轨迹切线旋转，不再程序绘制替代鲸鱼。仅使用Windows内置GDI/AlphaBlend，不增加外部运行时或新图像资源。绘制限制在气泡的水面区域，余额与峰谷文字独立。

运动：16秒循环。普通往返后先在水下转向蓄力；12.0–13.6秒为匀速水平、匀加速竖直的抛物线，起点(44,34)、最高点(32,20)、落点(20,34)。水下准备/恢复与空中位移、速度衔接，鲸鱼朝向跟随速度切线；14.4秒后恢复轻微浮动。

实施与验收：

1. 给旧版轨迹和图标颜色添加失败回归，确认问题可复现；核心断言验证起落点、最高点、水平速度、重力加速度、切线方向及衔接。
2. 新增独立的缓存图标绘制器，保留透明度并双线性采样；每次绘制复用DIB，GDI对象配对释放，DPI变化时重建缓存。
3. 完整构建与既有Windows/UI检查；真实窗口采集上升/顶点/下降帧，核对图标、旋转、余额隔离、红绿灯及GDI计数稳定。
4. 版本升至2.1.1，刷新README动画和本次验证证据；GitHub CI通过后发布并回下载核SHA，替换重启桌面入口，回收本轮临时文件。

风险与边界：原图头朝左，向右时须镜像且旋转符号相反；AlphaBlend不接受负宽高，镜像在像素采样中完成。透明像素须预乘Alpha，避免黑底/黑边；角度过大时不允许越过金额区域。仅为屏幕尺度的物理轨迹，不模拟完整水动力。回滚可重装v2.1.0，数据格式不变。
